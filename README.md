How to make an AI that "understands" mathematics like human mathematician would? Now, there are varying opinions about a human thinks, but a broad consensus is that we tend to have a very good understanding of higher-order features of our sensory input. That's what patterns are: they arise from our ability to detect similarities among seemingly different things by extracting meaningful representations and then compressing them. In this project, we will try to replicate the process of thought, which gives rise to intuition, computationally.


We will try toy model of the brain - a random walk (from one "thought" to the other). Then we can add weights/additional parameters so that it converges on specific values, using reinforcement learning techniques.
